LibreTours 360

An open-source, local-first editor for interactive 360° virtual tours.

Drop in your panoramas, link the scenes with hotspots, brand the tour with a theme and export a viewer you can share. Your projects never leave your machine.

Download Source on GitHub

Features

Multi-scene tours

Link equirectangular panoramas into a navigable tour. Reorder scenes by dragging, pick the start scene, rename in place.

Interactive hotspots

Navigation arrows to other scenes, with an optional return hotspot, and info points with Markdown content. Drag them right on the panorama.

Scene graph

A bird's-eye view of the whole tour: spot unreachable scenes, dead ends, one-way links and hotspots that point nowhere.

Floor plans

One plan per storey, with a minimap in the exported tour: a cone turns as you look around, and dots open the other scenes.

Measurement lines

Draw a labelled line between two points of a panorama. It stays on the edges you drew it on from any direction.

Theme builder

Logo, overlay images and text anchored to the viewport, a live preview over the panorama, and reusable .lt-theme presets.

Export anywhere

Web 3D

A Photo Sphere Viewer tour with full 3D navigation, ready to upload to any web server.

Standalone 3D

A folder that opens with a double-click on index.html: no server, no install, works from a USB stick.

Project package

A .ltproj file with the project and every image, to back it up or move it between the browser and the desktop app.

JSON

The project data alone, to use with other tools.

Download

Windows Portable, no installation macOS Apple Silicon Linux AppImage

The builds are not code-signed yet: Windows SmartScreen and macOS Gatekeeper may ask you to confirm before the first launch. Every release is listed on GitHub Releases, and you can always build from source.

Local-first, open source

No account, no cloud, no tracking. On the desktop each project is a folder on your disk; in the browser it lives in your own browser storage. LibreTours 360 is free software under the GPL-3.0 license, available in English and Italian.

Built with React, Photo Sphere Viewer and Tauri.
